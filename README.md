# MediFlow

## Descripción

MediFlow es un sistema de gestión clínica desarrollado como proyecto académico. Permite administrar información 
de pacientes, médicos, citas, horarios y otros procesos de una clínica.

## Tecnologías utilizadas

- C# y .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- MediatR
- Swagger

## Arquitectura

El proyecto utiliza Clean Architecture y está organizado en cuatro capas:

- **Domain:** entidades e interfaces.
- **Application:** casos de uso y DTOs.
- **Infrastructure:** acceso a datos y repositorios.
- **MediFlow:** API REST y configuración de servicios.
